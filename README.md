# swipe (micro:bit v2)

LEDマトリクスを光センサーとして使い、上をなぞった方向を8方位で検知するMakeCode拡張。外付け部品なし。

## 仕組み
LEDは逆バイアスして放電時間を測ると光センサーになる。
行5本・列5本をそれぞれ5個並列で測り、影の重心を追跡して始点→終点の角度を45°刻みにする。

## 注意
- v2の実機専用(シミュレーターは非対応、v1は何もしない)
- 測定中はLEDを一瞬消すので、表示は少し暗く・ちらつく
- 起動直後はLEDの上に何も置かない(基準の明るさを取る)
- 明るい場所のほうが安定する。反応が悪ければ `感度` を上げる

```blocks
swipe.onAnySwipe(function (direction) {
    basic.showArrow(swipe.toArrow(direction))
})
```
